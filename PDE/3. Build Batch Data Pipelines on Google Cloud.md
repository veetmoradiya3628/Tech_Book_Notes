
- As a data engineer, the core of your role is to build reliable pathways for data to move from raw sources to valuable insights. 
- batch data pipeline: These pipelines are the backbone of enterprise data strategy, responsible for processing large, finite datasets that are critical for everything from daily financial reconciliation to strategic business analytics.

- batch data pipelines
	- A batch data pipeline is a sequence of processes on one or more sets of data, designed to ingest, transform, and sink that data, in large, discrete chunks, or "batches", at scheduled intervals.
	- use cases
		- Periodic reporting
		- Large scale transformations
		- Data warehousing
		- Data migration
		- Scheduled backups
- components and stages
	- Data sources
		- Origin of your raw data, which can come in various formats (CSV, JSON, database tables, log files etc)
	- Data Ingestion
		- from source to 'landing zone' or 'staging area'
	- Data Transformation
		- Ingested data may be cleaned, validated, enriched, mapped, and/or restructured into a consistent and standardized format, before landing in the destination sink.
	- Data Sink
		- Final store
	- Downstream Uses
	- Orchestrate and Monitor

- Batch processing vs. batch pipelines
	- Batch data processing
		- The method or technique of handling data. It's about collecting data over a period (a "batch") and then processing that entire batch in a single, scheduled run.
	- Batch data pipelines
		- The entire automated system or infrastructure that implements batch data processing. It's the series of interconnected stages that systematically move and process data in batches from source to destination.
- Key features of batch data processing
	- Scheduled and automated
		- periodic execution jobs should have scheduled and automated nature
	- High throughput
		- rapid processing of large quantity of data records.
	- Latency
		- latency is allowed as this is "offline" behavior
	- Resource optimization
		- "burst" resource consumption
- pipeline challenges
	- Volume and scale
	- Data quality
	- Complexity and maintainability
	- Reliability, error handling, and observability
