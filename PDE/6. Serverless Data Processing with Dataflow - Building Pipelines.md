- Windows
	- Events out of order in streams
	- Windowing divides data into time-based, finite chunks
	- Required when doing aggregations over unbounded data using Beam primitives (GroupByKey, Combiners)
	- You can also do aggregations using state and timers
	- Processing time vs. Event time
	- Windowing by event time
	- Types of windows
		- Fixed
		- Sliding
		- Session
- Watermarks
	- Latency
	- The difference in time from when data was expected to arrive and when it actually arrived is called the lag time.
	- Data is late in comparison to the watermark
	- Metrics for watermark in dataflow
		- Data freshness
		- System latency
- Triggers
	- Event time
		- They operate on event time
	- Processing time
		- They operate on processing time
	- Composite
		- They combine multiple triggers
	- Data-driven
		- They operate by examining the data as it arrives and firing when it meets a certain condition
	- Custom triggers
